## General Information
- This is a application that allows users to paste in a sentence in a foreign language they're learning and get an explantion of the grammar and words used in their native language.
- It is also has a dictionary feature and a sentence correction feature.
- Originally made this to increase the efficiency of my personal Japanese language study. So rather than constantly writing out prompts to Chat GPT asking it to explain the meaning of a sentence, I made a wrapper that did this for me.

## Technologies Used
- Vite
- Typescript
- Golang
- OpenAI APIs

## Features
- A 'Sentence Analyser' that provides an explanation of the provided sentences meaning. Breaks down the meaning of each word and grammar structure used in the sentence and shows why it means what it means.
- A 'Dictionary' that defines, provides example sentences and synonyms of the word provided.
- A 'Correction' feature that corrects the users sentence if it has any mistakes.
